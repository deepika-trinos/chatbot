# Chatbot

A simple chatbot website built with only HTML, CSS and JavaScript, for practice.

## How to run

Open `index.html` in any web browser.

## Files

- `index.html` - page structure: chat window and history drawer
- `style.css` - all styling
- `js/storage.js` - saves and loads chats in localStorage
- `js/bot.js` - decides the bot's replies
- `js/ui.js` - draws messages and the history list
- `js/app.js` - connects the other files and handles clicks
